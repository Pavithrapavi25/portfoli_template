# P N Pavithra — Developer Portfolio

A modern, responsive personal portfolio website designed to showcase my **software development, full-stack, AI, data science, projects, internships, and hackathon experience** in one centralized platform.

The portfolio is built using **Next.js, React, TypeScript, Tailwind CSS, and Lucide React**, with a responsive dark-themed interface and deployed on **Vercel**.

## 📌 Project Overview

A professional portfolio is useful for presenting technical skills, projects, experience, and achievements to recruiters and hiring teams.

This portfolio provides a centralized platform to showcase:

* Software development skills
* Full-stack development experience
* Data science and AI projects
* Real-world business projects
* Internship experience
* Hackathon participation
* GitHub projects
* Contact and professional profiles

The website is designed to provide a simple and professional way for recruiters to explore my technical background.

---

## 💡 Solution

The portfolio organizes professional information into dedicated sections:

**About → Experience → Projects → Hackathons → Skills → Contact**

This allows visitors to quickly understand my technical background, project experience, and areas of interest.

The portfolio is also responsive so that it can be viewed across:

* Desktop
* Laptop
* Tablet
* Mobile devices

## 💻 Run Locally

### Clone the Repository

```bash
git clone https://github.com/Pavithrapavi25/portfoli_template.git
```

### Navigate to the Project

```bash
cd portfoli_template
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```

---

## 🏗️ Production Build

To create an optimized production build:

```bash
npm run build
```

To start the production server:

```bash
npm start
```
